## 🌟 What is WireWave?

WireWave is a premium, real-time messaging application that brings modern communication to life. Built with cutting-edge web technologies, it delivers a seamless, WhatsApp-style experience with enterprise-grade security and performance.

## ✨ Key Features

### 💬 **Core Messaging**
- **⚡ Real-time Messaging** - WebSocket-powered instant delivery with smart polling fallback
- **📱 WhatsApp-Style Interface** - Intuitive, beautiful design with dark theme
- **✅ Message Status** - Read receipts and delivery confirmations
- **💭 Typing Indicators** - See when contacts are composing messages
- **🟢 Online Presence** - Real-time online/offline status tracking

### 🎨 **User Experience**
- **📱 Mobile Responsive** - Seamless experience across all devices
- **🎭 Smooth Animations** - Framer Motion powered micro-interactions
- **🔍 Smart Search** - Find messages and contacts instantly
- **👥 Contact Management** - Automatic discovery from conversations
- **🎯 Reply & Delete** - Advanced message interaction controls

### 🔒 **Security & Performance**
- **🛡️ Enterprise Security** - JWT authentication with secure cookie storage
- **🚫 XSS Protection** - Content sanitization and CSP headers
- **⚡ Optimized Performance** - React Query caching and state management
- **🔄 Offline Support** - Smart fallback mechanisms for reliability

## 🚀 Quick Start Guide

### 📋 Prerequisites
```bash
Node.js 18+ ⚡
pnpm (recommended) or npm 📦
Git 🔧
```

### 🔧 Installation Steps

<details>
<summary><b>1. Clone the Repository</b></summary>

```bash
git clone https://github.com/UniquePratham/wire-wave.git
cd wire-wave
```
</details>

<details>
<summary><b>2. Install Dependencies</b></summary>

```bash
# Using pnpm (recommended)
pnpm install

# Using npm
npm install

# Using yarn
yarn install
```
</details>

<details>
<summary><b>3. Environment Configuration</b></summary>

Create your environment file:
```bash
cp .env.local.example .env.local
```

Configure the variables:
```env
# API Configuration
NEXT_PUBLIC_BACKEND_URL=http://65.20.91.194:3000
NEXT_PUBLIC_WS_URL=ws://65.20.91.194:3000

# App Configuration
NEXT_PUBLIC_APP_NAME=WireWave
COOKIE_NAME=wirewave_auth
COOKIE_SECRET=your-super-secret-cookie-key-change-in-production

# Environment
NODE_ENV=development
```
</details>

<details>
<summary><b>4. Launch Development Server</b></summary>

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser 🚀
</details>

### 🌐 Production Deployment

```bash
# Build for production
pnpm build

# Start production server
pnpm start

# Or deploy to Vercel
pnpm deploy
```

POST /register

```json

  "role": "user"

```
</details>

<details>
<summary><b>User Login</b></summary>

```http
POST /login
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "securepassword123"
}
```

**Response:**
```json
{
  "token": "<JWT_TOKEN>",
  "user": {
    "id": 1,
    "email": "user@example.com"
  }
}
```
</details>

<div align="center">

### 💬 Messaging Endpoints

</div>

<details>
<summary><b>Send Message</b></summary>

```http
POST /messages
Authorization: Bearer <JWT_TOKEN>
Content-Type: application/json

{
  "receiver_email": "recipient@example.com",
  "content": "Hello from WireWave! 👋"
}
```

**Response:**
```json
{
  "id": 1,
  "sender_email": "user@example.com",
  "receiver_email": "recipient@example.com",
  "content": "Hello from WireWave! 👋",
  "read": false,
  "sent_at": "2025-09-05T13:07:31.071Z"
}
```
</details>

<details>
<summary><b>Retrieve Messages</b></summary>

```http
GET /messages
Authorization: Bearer <JWT_TOKEN>
```

**Response:** Array of message objects
</details>

<details>
<summary><b>Mark as Read</b></summary>

```http
POST /messages/:message_id/read
Authorization: Bearer <JWT_TOKEN>
```

**Response:** Updated message with `read: true`
</details>

## ⚡ Real-Time Architecture

<div align="center">

### 🔄 Hybrid Communication System

</div>

WireWave employs a sophisticated dual-layer approach for maximum reliability:

<details>
<summary><b>🟢 Primary: WebSocket Connection</b></summary>

- **⚡ Instant message delivery** - Sub-100ms latency
- **💭 Live typing indicators** - Real-time feedback
- **🟢 Online presence tracking** - Instant status updates
- **✅ Read receipts** - Immediate delivery confirmation
- **🔌 Auto-reconnection** - Smart connection recovery

```javascript
// Example WebSocket integration
const socket = io(process.env.NEXT_PUBLIC_WS_URL);
socket.on('new_message', (message) => {
  // Instant message rendering
});
```
</details>

<details>
<summary><b>🔄 Fallback: Smart HTTP Polling</b></summary>

- **🛡️ Automatic activation** - When WebSocket fails
- **⏱️ Intelligent intervals** - 1.5-2.5 second adaptive polling
- **📈 Exponential backoff** - Reduces load when idle
- **🔍 Focus revalidation** - Updates on window focus
- **💾 React Query caching** - Efficient data management

```javascript
// Polling configuration
const { data } = useQuery({
  queryKey: ['messages'],
  queryFn: fetchMessages,
  refetchInterval: socketConnected ? false : 2000
});
```
</details>

<div align="center">

### 🚨 Common Issues & Solutions

</div>

<details>
<summary><b>🔐 Authentication Issues</b></summary>

**Problem:** 401 Unauthorized Errors
```bash
# Solutions:
✅ Check JWT token validity
✅ Verify backend API is running
✅ Clear cookies and re-login
✅ Check token expiration
```

**Problem:** Cookie Domain Issues
```bash
# Solutions:
✅ Ensure cookies match domain
✅ Check SameSite flags in production
✅ Verify HTTPS in production
```
</details>

<details>
<summary><b>🌐 Connection Problems</b></summary>

**Problem:** CORS Issues
```bash
# Solutions:
✅ Verify backend CORS configuration
✅ Check allowed origins
✅ Ensure preflight requests work
```

**Problem:** WebSocket Connection Failed
```bash
# Solutions:
✅ Verify WebSocket URL in .env
✅ Check backend WebSocket server
✅ Application auto-falls back to polling
✅ Check firewall/proxy settings
```
</details>

<details>
<summary><b>⚡ Performance Issues</b></summary>

**Problem:** Slow Message Loading
```bash
# Solutions:
✅ Check network connection
✅ Verify API response times
✅ Clear browser cache
✅ Check React Query cache
```

**Problem:** Memory Leaks
```bash
# Solutions:
✅ Check for unmounted component subscriptions
✅ Clear WebSocket listeners on unmount
✅ Monitor browser dev tools
```
</details>

## 🔐 Security Audit Checklist

<div align="center">

### ✅ Security Compliance Status

</div>

| Security Measure | Implementation | Status | Details |
|------------------|----------------|--------|---------|
| **Content Sanitization** | DOMPurify | ✅ | All user content sanitized |
| **XSS Prevention** | No unsafe innerHTML | ✅ | Strict content policies |
| **Cookie Security** | HttpOnly, SameSite=Strict | ✅ | Secure JWT storage |
| **CSRF Protection** | SameSite cookies | ✅ | Cross-site attack prevention |
| **Content Security Policy** | Strict CSP headers | ✅ | Script execution control |
| **Input Validation** | Zod schema validation | ✅ | All inputs validated |
| **Rate Limiting** | Client-side throttling | ✅ | Request frequency control |
| **Secure Headers** | HSTS, X-Frame-Options | ✅ | Browser security headers |

<details>
<summary><b>🔍 Security Implementation Details</b></summary>

```typescript
// Content Sanitization Example
import DOMPurify from 'dompurify';

const sanitizedContent = DOMPurify.sanitize(userInput, {
  ALLOWED_TAGS: ['p', 'br', 'strong', 'em'],
  ALLOWED_ATTR: []
});

// CSP Headers in _document.js
const csp = `
  default-src 'self';
  script-src 'self' 'unsafe-eval';
  style-src 'self' 'unsafe-inline';
  img-src 'self' data: https:;
  connect-src 'self' ws: wss:;
`;

// Zod Validation Schema
const messageSchema = z.object({
  content: z.string().min(1).max(2000),
  receiver_email: z.string().email()
});
```
</details>
